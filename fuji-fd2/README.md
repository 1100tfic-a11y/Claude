# FD2 × 富士スピードウェイ本コース　1分53秒台への目標データ

ホンダ シビックタイプR（FD2）で富士スピードウェイ本コース（4,563m）を **1分53秒台** で走るための資料。
公開されている実走記録、ホンダの公表諸元、物理モデルによる推定をまとめた。

| ファイル | 内容 |
|---|---|
| `data/reference_records.csv` | 富士の実走・比較記録（FD2、FL5、他車）と出典・確度 |
| `data/course_and_car.csv` | コースと FD2 の諸元（セクター計測点、ギア比など） |
| `data/sector_targets.csv` | ラップ目標ごとのセクター目標タイム |
| `data/gear_speed_table.csv` | ギアごとの車速（6100 / 8000 / 8400rpm） |
| `data/straight_top_speed_sim.csv` | ホームストレートの最高速シミュレーション（仕様別・立ち上がり速度別） |
| `data/straight_trace_normal_v0_105.csv` | ノーマル車の 50m ごとの速度・ギア・回転数 |
| `data/straight_sensitivity.csv` | ストレートでの速度差がラップに効く量 |
| `fd2_fuji_model.py` | 上の CSV を作る計算スクリプト（`python3 fd2_fuji_model.py`） |

> **データの確度について**：みんカラ、laptimerank、pro-iz、fsw.tv などは、この作業環境からはページ本文を取得できなかった。
> そのため実走記録の多くは **Web 検索結果の抜粋** から拾ったもので、元ページで確認していない。CSV の「確度」列を目安にし、使う前に元ページで確認すること。

## 1. 結論

| 項目 | 値 |
|---|---|
| 1:53.9 のセクター目標 | **S1 27.3 / S2 37.1 / S3 49.5** |
| 1:53.0 のセクター目標 | **S1 27.1 / S2 36.8 / S3 49.1** |
| 1コーナー手前の最高速（ノーマル、推定） | **約212〜214 km/h**（GPS 実速度ベース） |
| 1コーナー手前の最高速（吸排気＋ECU＋軽量化、推定） | **約215〜218 km/h**（5速レブ 217.9km/h が上限の目安） |
| 筑波 TC2000 に換算すると | **1分03秒台前半〜後半**（換算 1:04.0 ≒ 富士 1:54.1 から） |
| 一番縮める必要がある区間 | **S3（約−2.5秒）**。ストレートの最高速ではほとんど縮まらない |

1分53秒台は、ネット上で見つかる FD2 の富士の記録（1:57 前後）より **3〜4秒速い**。
FSW コースレコード表のシビック部門（FD2 改、1:57.223）より速く、
FL5（330PS ターボ）でも「目標 1:54.499」としているエントリーがある水準。
NA 2L の FD2 では **作り込んだ車＋上手いドライバー＋良い季節の、ほぼ理論値** と考えるのが妥当。

## 2. セクター目標タイム

富士の区間計測点は **S1 = 1,155m、S2 = 2,662m**（ループコイル位置）。区間長は S1 1,155m / S2 1,507m / S3 1,901m。

区間タイムの比率は、手に入った2例（Audi TT RS 1:50.089、FD2 1:59.454）で **ほぼ同じ**
（S1 約24.0%、S2 約32.6%、S3 約43.4%）。車種やタイムが違っても比率は大きく変わらないので、これで目標を割り振った。

| 目標 | S1 | S2 | S3 | 1:59.454 からの差（S1 / S2 / S3） |
|---|---|---|---|---|
| 1:57.000 | 28.05 | 38.13 | 50.83 | −0.6 / −0.7 / −1.2 |
| 1:55.500 | 27.69 | 37.64 | 50.18 | −1.0 / −1.2 / −1.8 |
| **1:53.999** | **27.33** | **37.15** | **49.53** | **−1.3 / −1.7 / −2.5** |
| 1:53.500 | 27.21 | 36.98 | 49.31 | −1.5 / −1.8 / −2.7 |
| 1:53.000 | 27.09 | 36.82 | 49.09 | −1.6 / −2.0 / −2.9 |

- 自分のロガーの区間タイムとこの表を比べ、**比率より遅い区間** から手を付ける。
- 比率がずれていたら、そこが弱点（例：S3 が 43.4% より大きい → 低速コーナーとトラクション）。
- 自分のベストのセクターをつないだ「理論ベスト」も必ず出しておく。

## 3. ホームストレートの最高速

### 3.1 ギアと車速（タイヤ外周 2.002m、最終減速比 4.764）

| ギア | 6100rpm（最大トルク） | 8000rpm（最高出力） | 8400rpm（レブ） |
|---|---|---|---|
| 3速 | 101 | 133 | 140 |
| 4速 | 127 | 166 | 175 |
| 5速 | 158 | 208 | **218** |
| 6速 | 197 | 259 | 272 |

### 3.2 シミュレーション（最終コーナー出口 → 1コーナーのブレーキングまで、約1,435m）

| 仕様 | 出口 95km/h | 出口 105km/h | 出口 115km/h |
|---|---|---|---|
| ノーマル | 212.4 | 213.3 | 214.2 |
| 吸排気＋ECU（出力 +5%） | 215.4 | 215.9 | 216.5 |
| 同上＋軽量化 50kg | 216.4 | 216.9 | 217.5 |
| 同上＋GT ウイング（CdA +0.06） | 214.7 | 214.8 | 215.3 |

ノーマル車の 50m ごとの速度（出口 105km/h）：250m で 151km/h（4速）→ 550m で 178km/h（5速）→ 1,000m で 200km/h → 1,300m で 211km/h。

**実測とのすり合わせ**

| 実測 | 値 | モデルとの比較 |
|---|---|---|
| ノーマルの雑誌テスト | 209 km/h | モデル 212〜214。誤差 2% 以内 |
| マフラー＋SPOON ECU、メーター読み | 220 km/h | メーターは数%多めに出るので、実速度は 210 台 |
| 仕様不明、メーター読み | 227 km/h | 5速レブ（218km/h）を超えるので、6速＋メーター誤差 |

**ストレートで分かること**

1. **最高速の差はタイムにあまり効かない。** 最高速が 5km/h 違っても、ストレート 1,200m での差は約 0.6〜0.7 秒。
   チューニングで最高速が 2〜4km/h 上がっても、0.3〜0.5 秒ほど。
2. **最終コーナーの立ち上がりが一番効く。** 出口速度が 95 → 115km/h になっても最高速は 2km/h しか変わらないが、
   ストレートの通過時間は **約1.2秒** 縮む（29.56 → 28.32 秒）。
3. **5速のまま 1コーナーまで引っ張るのが基本。** チューニング車は 1コーナー手前で 5速レブ（約218km/h）に当たる。
   6速に上げても 6,700rpm 前後で最大トルク付近から外れ、シフトで駆動が抜けるぶん得にならない。
   5速で当たるようになったら、ファイナル（4.4 前後）を変えるかどうかを検討する。
4. **気温で出力が変わる。** 富士は標高が約 550m なので空気密度は海面の約 94%（NA では 6% ほど出力が下がる）。
   気温 30℃ と 5℃ では空気密度が約 9% 違う。**アタックは 11〜2月の冷えた日** に。

## 4. NA 2L の FD2 で出せそうなタイム（推定）

| 段階 | 主な内容 | 富士の目安 | 根拠 |
|---|---|---|---|
| A | ノーマル、純正タイヤ | 2:00〜2:08 | 雑誌テスト 2:08.771、オーナーのベスト 1:59.454 |
| B | ハイグリップラジアル、パッド・フルード、アライメント | 1:57〜1:59 | スポーツラジアルで 1:57.1 |
| C | 車高調、機械式 LSD、S タイヤ（A052 / RE-71RS 級）、吸排気＋ECU | 1:55〜1:57 | FSW シビック部門レコード 1:57.223、FL5 のベスト 1:56.789 |
| D | C ＋軽量化 80〜120kg、エアロ（カナード・ウイング・ディフューザー）、255 幅 S タイヤ、230〜240PS | **1:53〜1:55** | 換算：筑波 1:04.0 ≒ 富士 1:54.1、「筑波 3 秒台レベルの FD2」の製作例あり |
| 参考 | 2.4L 換装（K24）など | 1:52 以下 | NA 2L ではないので対象外 |

**1分53秒台に必要な条件（NA 2L のほぼ理論値）**

- 車重（ドライバー込み）約 1,250kg 以下、出力 230PS 以上（パワーウェイトレシオ 5.4kg/PS 以下）
- 255 幅前後の S タイヤを、新しい状態で 1〜2 周目に使う
- ダウンフォースのあるエアロ（100R・最終セクションの速度が上がる）
- 気温 10℃ 以下、路面温度が高すぎない日
- ドライバーがセクターベストをつないだ理論ベストで 1:53 台を出せていること

## 5. 区間ごとのタイムの縮め方

1:59.454 → 1:53.999 の差 5.5 秒の配分は **S1 −1.3 / S2 −1.7 / S3 −2.5**。

| 区間 | 必要な短縮 | 主な項目 |
|---|---|---|
| S1（〜1,155m） | −1.3 秒 | 1コーナーのブレーキング（ブレーキ容量・パッド）、コカ・コーラコーナーの立ち上がり |
| S2（〜2,662m） | −1.7 秒 | 100R の速度（エアロ・タイヤ）、ヘアピンの進入と立ち上がり |
| S3（〜4,563m） | −2.5 秒 | ダンロップから最終コーナーまでの低速区間。**FF のトラクション（LSD）と、上り坂での立ち上がり**。ここの出口速度がそのままストレートのタイムになる |
