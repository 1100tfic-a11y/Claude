# ブロックコーチ — スクラッチ＆マイクロビット 学習支援アプリ

中学校 技術・家庭科（技術分野）「D 情報の技術／計測・制御」向けの、**1ファイル完結のHTMLアプリ**です。
生徒が「やりたいこと」を日本語の文章で書くと、対応するScratchのブロックとmicro:bit（MakeCode）のコードを提案します。
**マリオ風アクションゲームの制作を題材**に、必要なコードを網羅した **136パターン** を収録しています。

- ファイル：`block-coach.html`（これ1つだけ）
- **インターネット接続・インストール不要。** デスクトップに置いてダブルクリックで起動します
- 入力した文章や画像は外部に送信されません（すべてブラウザ内で処理）

### 主な仕掛け

- **.sb3 書き出し**：提案されたコードを Scratch プロジェクトファイルとしてダウンロードし、Scratch でそのまま開けます（拡張機能を含まないパターンのみ）
- **組み立て手順の自動生成**：「①コードエリアに『⚑ が押されたとき』を置く ②その下に『ずっと』を…」と、置く順番を1行ずつ表示します
- **MakeCodeコードのコピー**：MakeCode の JavaScript 画面に貼りつけると、ブロックに変換されます
- **印刷対応**：右上の「印刷」で、開いているタブをそのままワークシートとしてPDF保存・印刷できます
- **文字サイズ変更**：投影・視力配慮用

## 3. スクリーンショット診断について

スクラッチの画面を `Windows`+`Shift`+`S` で切り取り、アプリ上で `Ctrl`+`V` を押すと診断します（ドラッグ＆ドロップ、ファイル選択も可）。

**しくみ：** Scratchのブロックはカテゴリごとに色が決まっています（動き=青 #4C97FF、制御=橙 #FFAB19、イベント=黄 #FFBF00 …）。
画像中の色の分布・位置を解析し、次のような「形の誤り」を推定して、**画像に印と吹き出しを描いた図を生成**します。

- きっかけ（黄色のイベントブロック）が無い
- くりかえし・条件（オレンジ）が無い＝1回で終わる形
- 調べるブロック（水色）はあるのに判断（オレンジ）が無い
- きっかけブロックが最上部に無い
- 変数を使っているが初期化されていない可能性 など

生成した図は「画像を保存」でPNGとして保存でき、そのままワークシートや発表資料に使えます。

**正直な限界：** これは色の分布による推定であり、画像内の文字を読み取るAIではありません。
**数値の誤り（しきい値・歩数・秒数）や、ブロックの順序の誤りは検出できません。** 症状の選択と組み合わせて使ってください。

- 組めない生徒 → 「🧱 くみたて」の3択 →「📋 組み立て手順」で、必ず動くものを作る体験から

## 5. 重要な前提（教材研究用）

**Scratch公式の micro:bit 拡張機能には、光センサ・温度センサ・端子の入出力ブロックがありません。**

| | Scratch拡張機能 | MakeCode |
|---|---|---|
| ボタン・ジェスチャー・傾き・LED表示 | ✅ | ✅ |
| 明るさ・温度・アナログ入力 | ❌ | ✅ |
| デジタル/アナログ出力・サーボ・無線 | ❌ | ✅ |

したがって「計測・制御」の実習は **MakeCode が主戦場**になります。Scratchでは考え方（順次・分岐・反復、入力→処理→出力）を身につけ、実際のセンサ制御はMakeCodeで、という流れが無理がありません。
アプリ内の「📖 対応表」タブに、この対比と授業での組み立て方を掲載しています。
（Scratch上でセンサ値を扱いたい場合は、有志公開の拡張機能を使う方法もあります。アプリでは参考として緑色で表示していますが、導入は各校のネットワーク・端末の運用ルールをご確認のうえ、先生が動作確認をしてから判断してください。）

## 6. カスタマイズ（先生向け）

`block-coach.html` をテキストエディタで開き、次の配列を編集すると内容を増やせます。

| 場所 | 内容 |
|---|---|
| `const PATTERNS = [...]` | やりたいこと→コードの辞書。`kw2`（強いキーワード＝3点）と `kw`（1点）を増やすほど、生徒の言い回しに当たります |
| `SYMPTOMS.push(...)` / `const SYMPTOMS = [...]` | つまずき診断。学級でよく出る質問を追加してください |
| `const TRIG / LOOP / COND / ACT` | 「くみたて」タブの選択肢 |
| `const DICT / TERMS` | 対応表・用語辞典 |

編集前に必ずコピーを残してください。

## 7. 動作確認

- Chromium（Playwright）で全タブ・全機能の自動テストを実施：JavaScriptエラー 0件（136パターン・18症状のカード描画、組み立て手順の自動生成を含む）
- 生成される .sb3 を Scratch公式の検証ライブラリ `scratch-parser` で検証：**156件すべて合格**（パターン108件＋くみたての組み合わせ48件）
- 使用している全ブロック（90種類）の opcode・引数名・ドロップダウンの値を、**Scratch本体（scratch-vm）のソースと照合**して一致を確認
- 検索精度テスト：マリオ制作でよく出る38の言い回しで、期待するパターンが上位2件以内に入ることを確認（38/38）
- スクリーンショット診断は5種類のテスト画像で誤検出がないことを確認

想定環境：Windows / Chromium系ブラウザ（Edge・Chrome）。

### .sb3 書き出しについて

コードの中に出てくるスプライト（敵・コインなど）、コスチューム、背景、メッセージ、変数、リストは、
**名前だけの空の状態で自動的に作られます**。生徒は絵を描いて中身を作るところから始められます。
複数のかたまり（「旗が押されたとき」と「クローンされたとき」など）を含むパターンは、
Scratch上でも別々のスクリプトとして配置されます。
