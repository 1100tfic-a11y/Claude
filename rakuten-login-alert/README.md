# 楽天ログイン通知ウォッチャー

Gmail に届く **楽天のログイン通知メール** を、Google のクラウド（Google Apps Script）上で 5 分おきにチェックし、次の形式で通知します。PC やスマホの電源が切れていても動きます。

| ログイン元 | 通知内容 |
|---|---|
| 自分の iPhone（`133.106.50.64`） | 楽天アカウントにログインあり<br>自分の端末でログインしました<br>日時：2026/09/27 12:34 |
| それ以外 | 楽天アカウントにログインあり<br>他の端末からログインされました。<br>IPアドレス：203.0.113.45<br>日時：2026/09/27 12:34 |

## ファイル

- `Main.gs` … 設定・定期実行の本体
- `Logic.gs` … IP アドレスの取り出しと判定
- `Notify.gs` … 通知の送信
- `Test.gs` … テスト送信・調査用（`testNotify` / `testWithLatestMail` / `diagnose`）

4 つとも同じ Apps Script プロジェクトに入れてください（1 つのファイルにまとめて貼っても動きます）。
- `appsscript.json` … プロジェクト設定（タイムゾーン：東京）
- `test.js` … 判定ロジックのローカル確認用（`node test.js`）

## セットアップ（10 分程度）

1. PC で https://script.google.com を開き、**楽天の通知メールが届く Gmail と同じ Google アカウント** で「新しいプロジェクト」を作成
2. ファイルを 3 つ用意して貼り付け、保存（💾）
   - 最初からある `コード.gs` の中身を全部消し、`Main.gs` の内容を貼り付け
   - 左の「ファイル」の ＋ →「スクリプト」で `Logic` を作り、`Logic.gs` の内容を貼り付け
   - 同様に `Notify`、`Test` を作り、それぞれ貼り付け
   - **各ファイルの最後の行が `// ===== ここまで（○○.gs の最終行）=====` になっているか確認**してください。なっていなければコピーが途中で切れています
   - GitHub からコピーするときは、ファイルを開いて右上の「Raw」を押し、表示された全文をコピーすると確実です
3. 上部の関数選択で **`setup`** を選び「実行」
   - 権限の確認画面が出たら許可します（「このアプリは Google で確認されていません」→「詳細」→「（プロジェクト名）に移動」→ **「すべて選択」にチェック** →「続行」）
   - チェックを入れ忘れると、メール送信などが権限エラーになります
   - これで 5 分おきの自動チェックが始まります。すでに届いているメールは通知しません
4. 関数 **`testNotify`** を実行し、「自分の端末」「他の端末」の 2 通のテスト通知が届くことを確認
5. iPhone の Gmail アプリで通知をオンにしておく（設定 → 通知 → 「すべての新着メール」）

## 通知方法

初期設定は **自分の Gmail 宛てのメール**（件名：`楽天アカウントにログインあり`、他の端末の場合は `【要確認】楽天アカウントにログインあり`）です。
ほかの方法を使う場合は `Code.gs` の `CONFIG.NOTIFY` で `true` にし、Apps Script の「プロジェクトの設定 → スクリプト プロパティ」に値を登録します。

| 方法 | CONFIG.NOTIFY | スクリプト プロパティ |
|---|---|---|
| ntfy（iPhone アプリ「ntfy」でプッシュ通知、無料・登録不要） | `NTFY` | 不要（`CONFIG.NTFY_TOPIC` に直接書く。推測されにくい長い文字列にする） |
| Discord | `DISCORD` | `DISCORD_WEBHOOK_URL` |
| Slack | `SLACK` | `SLACK_WEBHOOK_URL` |
| LINE（Messaging API。※LINE Notify は 2025 年 3 月で終了） | `LINE` | `LINE_CHANNEL_TOKEN`, `LINE_USER_ID` |

## 設定の調整（`Code.gs` の `CONFIG`）

- **`MY_IPS`** … 自分の端末の IP。
  スマホのモバイル回線の IP は、再起動・機内モード・基地局の切り替えなどで **変わることがあります**。自分でログインしたのに「他の端末」と通知された場合は、その IP を追加するか、`'133.106.0.0/16'` のように範囲（CIDR）で指定してください。ただし範囲を広げるほど同じ回線の他人も「自分」と判定されるので、広げすぎないように。
  自宅 Wi-Fi でログインする場合は、自宅回線の IP も追加します。
- **`SEARCH_QUERY`** … 通知メールを探す Gmail 検索条件。楽天の通知メールの差出人・件名が変わって検知されない場合は、実際のメールに合わせて変更してください（Gmail の検索窓で同じ条件を試すと確認できます）。
- **`REQUIRE_DKIM`** … `true` のとき、楽天ドメイン（`rakuten.co.jp` / `rakuten.com`）の電子署名（DKIM）が確認できたメールだけを通知します。楽天をかたるフィッシングメールで誤った通知が出るのを防ぐためです。本物の通知が届かないときだけ `false` にしてください。
- **`CHECK_INTERVAL_MINUTES`** … チェック間隔（1 / 5 / 10 / 15 / 30 分）。変更したら `setup` を再実行。

## 「他の端末からログインされました」と届いたら

1. 楽天会員情報管理からパスワードを変更（他サービスと使い回していたら、そちらも変更）
2. 2 段階認証（ログイン時の本人確認）を有効化
3. 楽天カード・楽天ペイ・楽天ポイントの利用履歴を確認
4. 通知メール内のリンクからではなく、ブックマークや公式アプリから楽天にアクセスする

## うまく動かないとき

| 表示されるエラー | 原因と対処 |
|---|---|
| `SyntaxError: Unexpected end of input` | コードが途中までしか貼り付けられていません。各ファイルの最後が「ここまで」の行になっているか確認し、貼り直してください |
| `ReferenceError: ○○ is not defined` | 4 つのファイルのどれかが入っていません |
| `You do not have permission to call MailApp.sendEmail`（など `permission` を含むもの） | 許可画面で一部の権限にチェックが入っていませんでした。https://myaccount.google.com/connections でこのプロジェクトのアクセス権を削除し、`setup` を再実行して、許可画面で **「すべて選択」にチェック** してから続行してください |
| `通知に失敗しました` | 表示された通知方法の設定（URL・トピック名など）を確認してください |
| 通知が来ない | 下の「通知が来ないとき」を参照 |

### 通知が来ないとき

1. **`testNotify` を実行** → Gmail の受信トレイに通知メールが 2 通あるか確認
   - 受信トレイにあるのに iPhone が鳴らない：自分から自分宛てのメールは Gmail アプリが通知しないことがあります。**ntfy での通知がおすすめ**です（App Store で「ntfy」を入れ、アプリで好きなトピック名を購読し、同じ名前を `CONFIG.NTFY_TOPIC` に書いて `NOTIFY.NTFY` を `true` に）
2. **`diagnose` を実行** → 実行ログに、トリガーの有無と、過去 30 日に楽天から届いたメールの一覧（ログイン通知と判定されたか・DKIM・IP）が出ます
   - 楽天のログイン通知メールが「判定：いいえ」→ 件名に合わせて `SUBJECT_PATTERN` を変更
   - 「DKIM：NG」→ `REQUIRE_DKIM` を `false` に
3. **`testWithLatestMail` を実行** → 直近の楽天ログイン通知メールを使って、本番と同じ通知を送ります

なお `setup` は、その時点で届いているメールを通知しません。通知が来るのは、setup 後に新しくログインがあったときです。

## 停止するには

Apps Script の左メニュー「トリガー」から `checkRakutenLogin` のトリガーを削除します。
