# 授業ふりかえりアンケート（毎時間用）

生徒がタブレットで毎時間のふりかえりを入力し、先生がクラス別・授業別・個人別に閲覧できるツールです。
**Google スプレッドシート＋Apps Script（Webアプリ）** で動きます。回答はスプレッドシートに1行ずつ蓄積されるため、成績の評価材料としてそのまま残せます。

| ファイル | 役割 |
|---|---|
| `Code.gs` | サーバー側の処理（回答の保存・読み出し・パスコード確認）。**設定はこのファイル冒頭の `CONFIG`** |
| `Form.html` | 生徒用フォーム |
| `Teacher.html` | 先生用の集計・閲覧ページ |
| `appsscript.json` | Apps Script の設定（タイムゾーン＝日本 など） |

> 💡 `Form.html` と `Teacher.html` は、パソコンでダブルクリックして開くと **体験モード** で動きます（先生用パスコードは `demo`、サンプルデータ入り）。設置前に見た目と操作を確認できます。

---

## 1. 生徒の入力項目

| 項目 | 形式 | 必須 |
|---|---|---|
| 学年・組・出席番号 | 選択式（1年・2年は1〜6組、3年は1〜7組。番号は1〜35番） | ✅ |
| 時限 | 選択式（1〜6時間目） | ✅ |
| 氏名 | 自分で入力 | ✅ |
| ① 本時の授業の理解度 | A よく理解できた／B だいたい理解できた／C あまり理解できなかった | ✅ |
| 　その理由 | 記述 | ✅ |
| ② 本時の作業の進捗度 | A 予定より進んだ／B 予定どおり進んだ／C 予定より遅れている | ✅ |
| 　その理由 | 記述 | ✅ |
| ③ 質問・感想など | 記述 | 任意 |

- 授業日は送信した日が自動で入ります
- **学年・組・番号・氏名はタブレットに記憶され、2回目からは入力不要**（毎時間は ①〜③ だけ）
- 未入力があると、その欄が赤枠になって送信できません（サーバー側でも同じチェックをしています）
- タブレットのボタンを押しやすいよう A・B・C は大きなボタンにしています

## 2. 先生用ページでできること

| タブ | 内容 |
|---|---|
| 🏫 クラス一覧 | 縦＝生徒、横＝授業日の一覧表。各マスに「理解度／進捗度」を色つきで表示。生徒ごとの提出回数・理解度平均・進捗度平均・質問数、授業ごとの回答数・平均も表示 |
| 📅 授業ごと | 1回の授業の全員分の回答（理由・質問つき）。A/B/Cの人数グラフ、**未提出者の一覧**、「質問ありのみ」「Cをつけた生徒のみ」の絞り込み。次の授業の準備に |
| 👤 個人 | 1人分の全記録を時系列で表示。A/B/Cの回数・平均、推移（色の帯）、毎時間の理由。**「前の番号／次の番号」で順に見ていけるので、評価をつけるときに便利** |

- 期間（から・まで）を指定すると、学期ごとに集計できます
- 「印刷」でそのまま紙・PDFにできます（個人ページを印刷すれば個人カルテになります）
- 「CSV保存」で Excel 用のデータを保存できます
- 平均は **A=3・B=2・C=1** として計算しています
- 同じ生徒が同じ授業で2回以上送信した場合は、**最後の回答**を集計に使います（スプレッドシートにはすべて残ります）
- 名前の書き方が途中で変わった場合（例：「太郎」「技術太郎」）は、個人ページに「別の表記」として表示されます。集計は「学年・組・番号」で行うため、名前の揺れがあっても同じ人として扱われます

## 3. 設置方法（最初に1回だけ・約10分）

学校の Google アカウント（Google Workspace for Education）で行ってください。

1. Google ドライブで **新しいスプレッドシート** を作る（名前は「授業ふりかえり 2026」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 左の「ファイル」に、次の4つを作って中身を貼りつける
   - `コード.gs`（最初からあるもの）→ `Code.gs` の中身に置きかえる
   - ＋ → HTML → 名前 `Form` → `Form.html` の中身を貼りつける
   - ＋ → HTML → 名前 `Teacher` → `Teacher.html` の中身を貼りつける
   - ⚙ プロジェクトの設定 →「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック → `appsscript.json` の中身に置きかえる
4. `Code.gs` の冒頭の `TEACHER_PASSCODE: 'change-me'` を **自分だけが知っているパスコードに変更** して保存
   （教科名・クラス数・時限の数もここで変更できます）
5. 上の関数の選択で **`setup`** を選んで「実行」→ 権限の確認画面で「許可」
   （スプレッドシートに「回答」シートができます）
6. 右上の **デプロイ → 新しいデプロイ** → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校名）内の全員**
   - 「デプロイ」→ 表示された **ウェブアプリのURL** をコピー
7. 配布
   - **生徒用**：コピーしたURLそのまま → Google Classroom の「資料」やホーム画面のショートカットで配布
   - **先生用**：URLの最後に `?page=teacher` を付けたもの → 自分だけのブックマークに

> ⚠ `Code.gs` などを書きかえたあとは、**デプロイ → デプロイを管理 → ✏ 編集 → バージョン「新バージョン」→ デプロイ** をしないと反映されません（URLは変わりません）。

### 授業での使い方

- 授業の最後の3〜5分に「ふりかえりを送信しよう」と指示するだけです
- Classroom に URL を「資料」として1回置いておけば、毎時間同じURLで使えます
- 生徒のタブレット（iPad・Chromebook・Windows）のブラウザで動きます。アプリのインストールは不要です

## 4. データとセキュリティ

- 回答は **先生のスプレッドシートにだけ** 保存されます（外部のサービスには送られません）
- 生徒は **自分の回答を送ることしかできません**。他の生徒の回答を見る機能はありません
- 先生用ページはパスコードで保護しています。パスコードは `Code.gs`（サーバー側）にだけ書かれ、生徒の画面には送られません
- 生徒が学校のアカウントでログインしている場合は、スプレッドシートの「アカウント」列にメールアドレスも記録されます（なりすましの確認用）。先生用ページには表示しません
- 入力ミスの修正・削除は、スプレッドシートの「回答」シートを直接編集してください（列の並びは変えないでください）
- 記述欄は1つ1000文字まで。`=` などで始まる文字は数式にならないよう処理しています

## 5. カスタマイズ

| したいこと | 変更する場所 |
|---|---|
| クラス数・出席番号の上限 | `Code.gs` の `CONFIG.CLASSES` / `MAX_NUMBER` |
| 時限の欄をなくす | `Code.gs` の `MAX_PERIOD: 0` |
| フォームの見出しの教科名 | `Code.gs` の `SUBJECT` |
| A・B・C の説明文 | `Form.html` の `よく理解できた` などの文字 |
| 年度がかわったとき | スプレッドシートをコピーして新年度用にする（または「回答」シートの名前を変えて保管すると、新しい「回答」シートが自動で作られます） |

## 6. 動作確認

- `Code.gs`：Google のサービスを模した環境で、保存・入力チェック（3年8組や36番、空欄の理由、A/B/C以外の値は拒否）・絞り込み・パスコード確認をテスト
- `Form.html` / `Teacher.html`：Chromium（Playwright）で体験モードを操作し、未入力時のメッセージ、学年によるクラス数の切り替え（1年=6組、3年=7組）、端末への記憶、3つのタブ、CSV保存、氏名に記号を入れた場合の表示（HTMLとして解釈されないこと）を確認。JavaScript エラー 0件、スマホ幅（390px）で横スクロールなし
