# 授業ふりかえりアンケート（毎時間用）

生徒がタブレットで毎時間のふりかえりを入力し、先生がクラス別・授業別・個人別に閲覧できるツールです。
**Google スプレッドシート＋Apps Script（Webアプリ）** で動きます。回答はスプレッドシートに1行ずつ蓄積されるため、成績の評価材料としてそのまま残せます。

| ファイル | 役割 |
|---|---|
| **`furikaeri.gs`** | **Apps Script に貼りつけるのはこの1ファイルだけ**（プログラムと画面がすべて入っています） |
| `src/Form.html` | 生徒用フォームの元ファイル。パソコンでダブルクリックすると **体験モード** で動きます |
| `src/Teacher.html` | 先生用ページの元ファイル。同じく体験モードで動きます（パスコードは `demo`、サンプルデータ入り） |
| `src/server.gs`・`src/build.js` | 開発用（`node src/build.js` で `furikaeri.gs` を作り直します）。先生は使いません |

---

## 1. 生徒の入力項目

| 項目 | 形式 | 必須 |
|---|---|---|
| 学年・組・出席番号 | 選択式（1年・2年は1〜6組、3年は1〜7組。番号は1〜35番） | ✅ |
| 時限 | 選択式（1〜6時間目） | ✅ |
| 氏名 | 自分で入力 | ✅ |
| ① 本時の授業の理解度 | A よく理解できた／B だいたい理解できた／C あまり理解できなかった | ✅ |
| 　その理由 | 記述 | ✅ |
| ② 本時の作業の進捗度 | A 予定より進んだ／B 予定どおり進んだ／C 予定より遅れている | ✅ |
| 　その理由 | 記述 | ✅ |
| ③ 質問・感想など | 記述 | 任意 |
| 🔑 合言葉 | 先生が黒板（画面）に示したもの | ✅（「使わない」設定にすると欄が消えます） |

- 授業日は送信した日が自動で入ります
- **学年・組・番号・氏名はタブレットに記憶され、2回目からは入力不要**（毎時間は ①〜③ だけ）
- 未入力があると、その欄が赤枠になって送信できません（サーバー側でも同じチェックをしています）
- タブレットのボタンを押しやすいよう A・B・C は大きなボタンにしています

## 2. 先生用ページでできること

| タブ | 内容 |
|---|---|
| 🏫 クラス一覧 | 縦＝生徒、横＝授業日の一覧表。各マスに「理解度／進捗度」を色つきで表示。生徒ごとの提出回数・理解度平均・進捗度平均・質問数、授業ごとの回答数・平均も表示 |
| 📅 授業ごと | 1回の授業の全員分の回答（理由・質問つき）。A/B/Cの人数グラフ、**未提出者の一覧**、「質問ありのみ」「Cをつけた生徒のみ」の絞り込み。次の授業の準備に |
| 👤 個人 | 1人分の全記録を時系列で表示。A/B/Cの回数・平均、推移（色の帯）、毎時間の理由。**「前の番号／次の番号」で順に見ていけるので、評価をつけるときに便利** |

- 期間（から・まで）を指定すると、学期ごとに集計できます
- 一番上の「🔑 合言葉」で、今日の合言葉の確認と設定の変更ができます（下の「3. 合言葉」）
- 「印刷」でそのまま紙・PDFにできます（個人ページを印刷すれば個人カルテになります）
- 「CSV保存」で Excel 用のデータを保存できます
- 平均は **A=3・B=2・C=1** として計算しています
- 同じ生徒が同じ授業で2回以上送信した場合は、**最後の回答**を集計に使います（スプレッドシートにはすべて残ります）
- 名前の書き方が途中で変わった場合（例：「太郎」「技術太郎」）は、個人ページに「別の表記」として表示されます。集計は「学年・組・番号」で行うため、名前の揺れがあっても同じ人として扱われます

## 3. 合言葉

授業に出ている生徒だけが送信できるようにするしくみです。URLが学校外に広まっても、合言葉を知らない人は送信できません。
**設定は先生用ページの「🔑 合言葉」から変えられます**（コードの書きかえ・再デプロイは不要）。

| 方式 | 先生の手間 | 向いている場面 |
|---|---|---|
| **毎日自動でかわる**（最初はこれ） | **なし**。先生用ページを開くと「今日の合言葉（4けたの数字）」が表示されるので、それを板書するだけ | ふだんの授業。昨日の合言葉は今日は使えないので、授業後に家から送るなども防げる |
| **自分で決める** | 一度決めれば、変えるまで同じ | 「学期中はずっと同じ」でよいとき。覚えやすい言葉にできる |
| **使わない** | なし | 生徒が学校のアカウントでログインしている場合など |

- 合言葉は **1日ごと**（同じ日なら何時間目でも同じ）です。全クラス共通です
- 「大きく表示」を押すと、合言葉を画面いっぱいに表示します（プロジェクター・電子黒板用）
- 全角・半角、大文字・小文字、カタカナの全角・半角の違いは区別しません（「１２３４」でも「1234」でもOK）
- 合言葉は生徒の端末には記憶しません（毎回入力します）
- 毎日の合言葉が外部に知られてしまったときは「毎日の合言葉を作り直す」を押すと、その日以降の合言葉がすべて別の数字になります
- 合言葉のまちがいは、サーバー側でも確認しています（生徒の画面を改造しても通りません）

## 4. 設置方法（最初に1回だけ・約15分）

学校の Google アカウント（Google Workspace for Education）で、**パソコン**で行ってください。
やることは **A. 貼りつける → B. パスコードを決める → C. 公開する → D. 配る** の4段階です。

### A. スプレッドシートを作り、コードを貼りつける

1. Google ドライブで **「＋新規」→「Google スプレッドシート」** を押し、新しいスプレッドシートを作る
   左上の「無題のスプレッドシート」を押して、名前を「授業ふりかえり 2026」などに変える
2. スプレッドシートの上のメニューから **「拡張機能」→「Apps Script」** を押す
   → 別のタブで Apps Script の画面が開きます
3. 画面の左に「ファイル」の一覧があり、**「コード.gs」** が1つだけあります。それを押すと、右側に次の3行が表示されています
   ```
   function myFunction() {

   }
   ```
4. 右側をクリックして **Ctrl＋A（すべて選択）→ Delete** で、この3行を消す（何もない状態にする）
5. このリポジトリの **`furikaeri.gs`** を開き、**中身をすべてコピー**する
   - GitHub で開いた場合：ファイルの右上にある **「Copy raw file」（四角が2つ重なったアイコン）** を押すと全部コピーされます
   - ファイルを受け取った場合：メモ帳で開き、Ctrl＋A → Ctrl＋C
6. Apps Script の「コード.gs」の右側に **Ctrl＋V で貼りつけ**、**Ctrl＋S（または 💾 アイコン）で保存**
   （1200行ほどあります。最初の行が `// ====` で始まっていればOK）

> ファイルを追加したり、名前を変えたりする必要はありません。「コード.gs」1つだけで動きます。

### B. 先生用パスコードを決める（コードの書きかえは不要）

7. **スプレッドシートのタブ**（Apps Script ではない方）に戻り、**ページを再読み込み**（F5）する
8. 数秒待つと、メニューの「ヘルプ」の右に **「ふりかえり」** が出てくる
9. **「ふりかえり」→「先生用パスコードを設定する」** を押す
10. 初回だけ **「承認が必要です」** と出るので、次のように進める
    - 「続行」→ 自分のアカウントを選ぶ →（「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）（安全ではないページ）に移動」）→ **「許可」**
    - これは「このプログラムが自分のスプレッドシートを使ってよいか」の確認です。自分で作ったプログラムなので許可して大丈夫です
11. 許可したあと、もう一度 **「ふりかえり」→「先生用パスコードを設定する」** を押す
12. 入力欄に **自分で決めたパスコード（4文字以上）** を入れて「OK」
    → 「パスコードを設定しました」と出て、シートの下に **「回答」シート** ができます

> パスコードは生徒に教えないでください。忘れたときは、同じメニューからいつでも設定し直せます。

### C. ウェブアプリとして公開する（デプロイ）

13. **Apps Script のタブ**に戻り、右上の青いボタン **「デプロイ」→「新しいデプロイ」** を押す
14. 「種類の選択」の横の **⚙（歯車）→「ウェブアプリ」** を選ぶ
15. 次のように設定する
    | 項目 | 設定 |
    |---|---|
    | 説明 | 空欄でOK（「ふりかえり」など何でも） |
    | 次のユーザーとして実行 | **自分（自分のメールアドレス）** |
    | アクセスできるユーザー | 生徒が学校の Google アカウントでログインしている → **「（学校名）内の全員」**<br>生徒が Google アカウントを持っていない → **「全員」** |
16. **「デプロイ」** を押す（「アクセスを承認」と出たら、10. と同じように許可する）
17. **「ウェブアプリ」の URL**（`https://script.google.com/macros/s/……/exec`）が表示されるので **「コピー」** してメモしておく → 「完了」

> 「全員」が選択肢に出ないときは、学校の管理設定でドメイン外への公開が禁止されています。情報担当の先生・管理者に相談してください。

### D. 生徒に配る・先生用ページを開く

18. **生徒用**：17. の URL をそのまま、Google Classroom の「資料」や Teams などで配布する
    （タブレットのホーム画面に追加しておくと、毎時間すぐ開けます）
19. **先生用**：17. の URL の最後に **`?page=teacher`** を付けて開く
    例）`https://script.google.com/macros/s/AKfy……/exec?page=teacher`
    → B. で決めたパスコードを入れると集計画面と **今日の合言葉** が表示されます。ブックマークしておきましょう
20. 試しに自分で生徒用 URL から1回送信し、先生用ページに出てくれば設置完了です

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| メニューに「ふりかえり」が出ない | 貼りつけ後に保存したか確認 → スプレッドシートを再読み込み（F5）して数秒待つ |
| 先生用ページで「パスコードがまだ設定されていません」 | B. の手順でパスコードを設定する |
| 生徒が「アクセス権がありません」と出る | 15. の「アクセスできるユーザー」を確認。変えるときは「デプロイ」→「デプロイを管理」→ ✏ →変更→「デプロイ」 |
| 合言葉がちがうと言われる | 先生用ページで今日の合言葉を確認。「毎日自動でかわる」なので前の日の数字は使えません |

> ⚠ **あとから `furikaeri.gs` を新しいものに貼りかえたとき**は、「デプロイ」→「デプロイを管理」→ ✏（編集）→ バージョン **「新バージョン」** →「デプロイ」をしないと、生徒の画面に反映されません（URLは変わりません）。パスコードと回答データは残ります。

### 授業での使い方

1. 授業の最後に先生用ページを開き、**今日の合言葉**を板書する（「大きく表示」でプロジェクターに映してもOK）
2. 「ふりかえりを送信しよう」と指示する（3〜5分）
3. 生徒のタブレット（iPad・Chromebook・Windows）のブラウザで動きます。アプリのインストールは不要です

## 5. データとセキュリティ

- 回答は **先生のスプレッドシートにだけ** 保存されます（外部のサービスには送られません）
- 生徒は **自分の回答を送ることしかできません**。他の生徒の回答を見る機能はありません
- 先生用ページはパスコードで保護しています。パスコードはプログラムの中には書かれず、Google のサーバー側（スクリプト プロパティ）に保存されます。生徒の画面には送られません
- 「全員」で公開した場合、だれが送ったかは確認できません（なりすましは防げません）。合言葉は「授業に出ていない人からの送信」を防ぐためのものです
- 生徒が学校のアカウントでログインしている場合は、スプレッドシートの「アカウント」列にメールアドレスも記録されます（なりすましの確認用）。先生用ページには表示しません
- 入力ミスの修正・削除は、スプレッドシートの「回答」シートを直接編集してください（列の並びは変えないでください）
- 記述欄は1つ1000文字まで。`=` などで始まる文字は数式にならないよう処理しています

## 6. カスタマイズ

ふつうは変更不要です。変える場合は、Apps Script の「コード.gs」（貼りつけた `furikaeri.gs`）を直接書きかえて保存し、上の「新バージョン」でデプロイし直してください。

| したいこと | 変更する場所（「コード.gs」の中） |
|---|---|
| クラス数・出席番号の上限 | 上のほうの `CONFIG` の `CLASSES` / `MAX_NUMBER` |
| 時限の欄をなくす | `CONFIG` の `MAX_PERIOD: 6` を `0` に |
| フォームの見出しの教科名 | `CONFIG` の `SUBJECT: '技術'` |
| A・B・C の説明文 | Ctrl＋F で `よく理解できた` などを探して書きかえる |
| 年度がかわったとき | スプレッドシートを「ファイル」→「コピーを作成」して新年度用にする（コピーしたものは A.〜C. の B・C をやり直し） |

## 7. 動作確認

- `furikaeri.gs`：Google のサービスを模した環境で、回答の保存と入力チェック（3年8組や36番、空欄の理由、A/B/C以外の値は拒否）、合言葉（3方式の切り替え、まちがい・空欄の拒否、全角入力、日付ごとに変わること、作り直し）、メニューからのパスコード設定（4文字未満は拒否）、未設定時のメッセージ、絞り込みをテスト。埋めこんだ画面（HTML）が元ファイルと1文字も違わないことも確認
- `src/Form.html` / `src/Teacher.html`：Chromium（Playwright）で体験モードを操作し、未入力時のメッセージ、学年によるクラス数の切り替え（1年=6組、3年=7組）、端末への記憶、3つのタブ、合言葉（先生用ページで表示した合言葉で送信できる・まちがいは赤枠で止まる・方式の切り替え）、CSV保存、氏名に記号を入れた場合の表示（HTMLとして解釈されないこと）を確認。JavaScript エラー 0件、スマホ幅（390px）で横スクロールなし
