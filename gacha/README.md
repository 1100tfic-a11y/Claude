# 授業ふりかえりアンケート ガチャ版（毎時間用）

[`furikaeri/`](../furikaeri/README.md)（タマゴ育成版）と**ふりかえりの部分はまったく同じ**で、タマゴの育成のかわりに **ふりかえりを送信するたびにガチャを1回引ける** ようにしたものです。
**Google スプレッドシート＋Apps Script（Webアプリ）** で動きます。タマゴ育成版とは別のスプレッドシートに設置してください。

| ファイル | 役割 |
|---|---|
| **`gacha.gs`** | **Apps Script に貼りつけるのはこの1ファイルだけ**（プログラムと画面とキャラの絵がすべて入っています） |
| `gacha.txt` | `gacha.gs` とまったく同じ中身のテキストファイル（`.gs` を開けない端末で中身を見る・コピーする用） |
| `gacha-copy.html` | `gacha.gs` の中身を表示するページ。**「すべてコピー」ボタン** で全部コピーできます |
| `src/Form.html` | 生徒用フォームの元ファイル。パソコンでダブルクリックすると **体験モード** で動きます（ガチャも引けます） |
| `src/Teacher.html` | 先生用ページの元ファイル（タマゴ育成版と同じ）。体験モードのパスコードは `demo` |
| `src/chars.js` | **ガチャから出るキャラの一覧**（名前・レア度） |
| `art/` | キャラの絵を置くフォルダ（ファイル名 = キャラの id。例：`art/c01.png`） |
| `src/char-images.js` | `art/` の絵を小さくして埋めこんだもの（`tools/add_chars.py` で自動作成） |
| `src/server.gs`・`src/build.js` | 開発用（`node src/build.js` で `gacha.gs` を作り直します）。先生は使いません |

> 今入っている12体（サンプル1〜12）は **仮のキャラ** です。本物のキャラの絵がそろったら差しかえます（下の「3-1. キャラの追加・差しかえ」）。

## 1. 生徒の入力項目

| 項目 | 形式 | 必須 |
|---|---|---|
| 学年・組・出席番号 | 選択式（1年・2年は1〜6組、3年は1〜7組。番号は1〜35番） | ✅ |
| 時限 | 選択式（1〜6時間目） | ✅ |
| 氏名 | 自分で入力 | ✅ |
| ① 本時の授業の理解度 | A よく理解できた／B だいたい理解できた／C あまり理解できなかった | ✅ |
| 　その理由 | 記述 | ✅ |
| ② 本時の作業の進捗度 | A 予定より進んだ／B 予定どおり進んだ／C 予定より遅れている | ✅ |
| 　その理由 | 記述 | ✅ |
| ③ 質問・感想など | 記述 | 任意 |
| 🔑 合言葉 | 先生が黒板（画面）に示したもの | ✅（「使わない」設定にすると欄が消えます） |

- 授業日は送信した日が自動で入ります
- **学年・組・番号・氏名はタブレットに記憶され、2回目からは入力不要**（毎時間は ①〜③ だけ）
- 未入力があると、その欄が赤枠になって送信できません（サーバー側でも同じチェックをしています）
- タブレットのボタンを押しやすいよう A・B・C は大きなボタンにしています

## 2. 先生用ページでできること

| タブ | 内容 |
|---|---|
| 🏫 クラス一覧 | 縦＝生徒、横＝授業日の一覧表。各マスに「理解度／進捗度」を色つきで表示。生徒ごとの提出回数・理解度平均・進捗度平均・質問数、授業ごとの回答数・平均も表示 |
| 📅 授業ごと | 1回の授業の全員分の回答（理由・質問つき）。A/B/Cの人数グラフ、**未提出者の一覧**、「質問ありのみ」「Cをつけた生徒のみ」の絞り込み。次の授業の準備に |
| 👤 個人 | 1人分の全記録を時系列で表示。A/B/Cの回数・平均、推移（色の帯）、毎時間の理由。**「前の番号／次の番号」で順に見ていけるので、評価をつけるときに便利** |

- 期間（から・まで）を指定すると、学期ごとに集計できます
- **回答の削除**：「📅 授業ごと」「👤 個人」で、消したい回答にチェックを入れて「選んだ回答を削除」。試しに取ったアンケートは「この授業の回答をすべて削除」で1回分まとめて消せます（下の「回答を消したいとき」）
- 一番上の「🔑 合言葉」で、今日の合言葉の確認と設定の変更ができます（下の「3-2. 合言葉」）
- 「印刷」でそのまま紙・PDFにできます（個人ページを印刷すれば個人カルテになります）
- 「CSV保存」で Excel 用のデータを保存できます
- 平均は **A=3・B=2・C=1** として計算しています
- 同じ生徒が同じ授業で2回以上送信した場合は、**最後の回答**を集計に使います（スプレッドシートにはすべて残ります）
- 名前の書き方が途中で変わった場合（例：「太郎」「技術太郎」）は、個人ページに「別の表記」として表示されます。集計は「学年・組・番号」で行うため、名前の揺れがあっても同じ人として扱われます

## 3. ガチャ

ふりかえりを送信するたびに、ガチャを1回引けます。毎時間の提出の楽しみになるしくみです。

1. 送信すると、**ガチャのマシン** と「🎰 ガチャを回す！」ボタンが出ます
2. 押すと、ハンドルが回る → カプセルが落ちる → ぶるぶる → パカッと開いてキャラが出ます
   - カプセルの色でレア度がわかります（**N**＝灰、**R**＝青、**SR**＝紫、**SSR**＝金）。SR・SSR は画面が光り、SSR は虹色の光が回ります
   - はじめて出たキャラには **NEW!**、持っているキャラは「〇体目」と表示されます
3. フォームを開くと、いちばん上に **ガチャ図鑑**（集めた数／全体の数）と「今日はあと何回引けるか」が出ます
   - 「図鑑を見る」で全キャラの一覧。まだ持っていないキャラは「？」で、名前もかくれています
   - 出る確率もここに表示されます（最初は **N 60%・R 28%・SR 10%・SSR 2%**）

**ずるができないしくみ**
- ガチャを引けるのは **1回の授業（日付＋時限）につき1回** だけです。同じ授業で何度送信しても引けません
- **1日に2回まで**（2時間続きの授業を想定）。時限を変えて何度も送っても、3回目以降は引けません
- **何が出るかはサーバー（Apps Script）が送信のときに決めて、その場で記録します。** 画面の「回す」ボタンは演出だけなので、画面を改造したり、途中でページを閉じたりしても結果は変わりません（閉じても、引いたキャラは図鑑に入っています）
- 図鑑を見ることはできますが、ほかの人の番号でガチャを引くことはできません（引けるのは送信した直後だけ）

**先生が知っておくこと**
- スプレッドシートに次の2つのシートが自動でできます
  - **「ガチャ」シート**：生徒1人1行（学年-組-番号ごと）。引いた回数と、持っているキャラ（`c01:2,c07:1` ＝ c01 を2体、c07 を1体）
  - **「ガチャ履歴」シート**：引くたびに1行（日時・授業・生徒・出たキャラ・レア度・はじめてか）
- **やり直したい生徒がいるとき**は、「ガチャ」シートのその生徒の行を削除すると、図鑑が空になります
- 回答を削除しても、引いたキャラは消えません

### 3-1. キャラの追加・差しかえ

1. キャラの絵を `art/` に置く。ファイル名はキャラの id にする（`c01.png`、`c02.jpg` など。PNG・JPEG・WebP・GIF）
   背景が透明な PNG がいちばんきれいに出ます。大きい絵でも自動で 320 ピクセルに縮めます
2. `src/chars.js` の `LIST` に、id・名前・レア度を書く
   ```js
   { id:'c01', name:'〇〇', rarity:'N' },
   ```
   レア度は `N`・`R`・`SR`・`SSR` の4つ。**図鑑はこの順に並びます**。仮のキャラ（`sample:true`）は消してかまいません
3. `python3 tools/add_chars.py` → `node src/build.js` を実行すると `gacha.gs` ができます
4. Apps Script に貼りかえて、「新バージョン」でデプロイし直す（下の ⚠）

- キャラのいないレア度は出ません（たとえば SSR のキャラが0体なら、残りのレア度の割合で出ます）
- **id は一度使ったら変えないでください**（生徒の図鑑は id で記録しています）。キャラを消すと、そのキャラは図鑑に出なくなります（記録はシートに残るので、戻せば復活します）
- 絵が無いキャラは、レア度の色のカードに `emoji` の絵で表示されます
- 絵1枚は 10〜40KB ほどです。100体入れても `gacha.gs` は数MB以内に収まります

## 3-2. 合言葉

授業に出ている生徒だけが送信できるようにするしくみです。URLが学校外に広まっても、合言葉を知らない人は送信できません。
**設定は先生用ページの「🔑 合言葉」から変えられます**（コードの書きかえ・再デプロイは不要）。

| 方式 | 先生の手間 | 向いている場面 |
|---|---|---|
| **毎日自動でかわる**（最初はこれ） | **なし**。先生用ページを開くと「今日の合言葉（4けたの数字）」が表示されるので、それを板書するだけ | ふだんの授業。昨日の合言葉は今日は使えないので、授業後に家から送るなども防げる |
| **自分で決める** | 一度決めれば、変えるまで同じ | 「学期中はずっと同じ」でよいとき。覚えやすい言葉にできる |
| **使わない** | なし | 生徒が学校のアカウントでログインしている場合など |

- 合言葉は **1日ごと**（同じ日なら何時間目でも同じ）です。全クラス共通です
- 「大きく表示」を押すと、合言葉を画面いっぱいに表示します（プロジェクター・電子黒板用）
- 全角・半角、大文字・小文字、カタカナの全角・半角の違いは区別しません（「１２３４」でも「1234」でもOK）
- 合言葉は生徒の端末には記憶しません（毎回入力します）
- 毎日の合言葉が外部に知られてしまったときは「毎日の合言葉を作り直す」を押すと、その日以降の合言葉がすべて別の数字になります
- 合言葉のまちがいは、サーバー側でも確認しています（生徒の画面を改造しても通りません）

## 4. 設置方法（最初に1回だけ・約15分）

学校の Google アカウント（Google Workspace for Education）で、**パソコン**で行ってください。
やることは **A. 貼りつける → B. パスコードを決める → C. 公開する → D. 配る** の4段階です。

### A. スプレッドシートを作り、コードを貼りつける

1. Google ドライブで **「＋新規」→「Google スプレッドシート」** を押し、新しいスプレッドシートを作る
   左上の「無題のスプレッドシート」を押して、名前を「授業ふりかえり 2026」などに変える
2. スプレッドシートの上のメニューから **「拡張機能」→「Apps Script」** を押す
   → 別のタブで Apps Script の画面が開きます
3. 画面の左に「ファイル」の一覧があり、**「コード.gs」** が1つだけあります。それを押すと、右側に次の3行が表示されています
   ```
   function myFunction() {

   }
   ```
4. 右側をクリックして **Ctrl＋A（すべて選択）→ Delete** で、この3行を消す（何もない状態にする）
5. このリポジトリの **`gacha/gacha.gs`** を開き、**中身をすべてコピー**する
   - GitHub で開いた場合：ファイルの右上にある **「Copy raw file」（四角が2つ重なったアイコン）** を押すと全部コピーされます
   - ファイルを受け取った場合：メモ帳で開き、Ctrl＋A → Ctrl＋C
6. Apps Script の「コード.gs」の右側に **Ctrl＋V で貼りつけ**、**Ctrl＋S（または 💾 アイコン）で保存**
   （最初の行が `// ====` で始まっていればOK。キャラの絵が入っているので、キャラが多いと大きなファイルになります）

> ファイルを追加したり、名前を変えたりする必要はありません。「コード.gs」1つだけで動きます。

### B. 先生用パスコードを決める（コードの書きかえは不要）

7. **スプレッドシートのタブ**（Apps Script ではない方）に戻り、**ページを再読み込み**（F5）する
8. 数秒待つと、メニューの「ヘルプ」の右に **「ふりかえり」** が出てくる
9. **「ふりかえり」→「先生用パスコードを設定する」** を押す
10. 初回だけ **「承認が必要です」** と出るので、次のように進める
    - 「続行」→ 自分のアカウントを選ぶ →（「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）（安全ではないページ）に移動」）→ **「許可」**
    - これは「このプログラムが自分のスプレッドシートを使ってよいか」の確認です。自分で作ったプログラムなので許可して大丈夫です
11. 許可したあと、もう一度 **「ふりかえり」→「先生用パスコードを設定する」** を押す
12. 入力欄に **自分で決めたパスコード（4文字以上）** を入れて「OK」
    → 「パスコードを設定しました」と出て、シートの下に **「回答」シート** ができます

> パスコードは生徒に教えないでください。忘れたときは、同じメニューからいつでも設定し直せます。

### C. ウェブアプリとして公開する（デプロイ）

13. **Apps Script のタブ**に戻り、右上の青いボタン **「デプロイ」→「新しいデプロイ」** を押す
14. 「種類の選択」の横の **⚙（歯車）→「ウェブアプリ」** を選ぶ
15. 次のように設定する
    | 項目 | 設定 |
    |---|---|
    | 説明 | 空欄でOK（「ふりかえり」など何でも） |
    | 次のユーザーとして実行 | **自分（自分のメールアドレス）** |
    | アクセスできるユーザー | 生徒が学校の Google アカウントでログインしている → **「（学校名）内の全員」**<br>生徒が Google アカウントを持っていない → **「全員」** |
16. **「デプロイ」** を押す（「アクセスを承認」と出たら、10. と同じように許可する）
17. **「ウェブアプリ」の URL**（`https://script.google.com/macros/s/……/exec`）が表示されるので **「コピー」** してメモしておく → 「完了」

> 「全員」が選択肢に出ないときは、学校の管理設定でドメイン外への公開が禁止されています。情報担当の先生・管理者に相談してください。

### D. 生徒に配る・先生用ページを開く

18. **生徒用**：17. の URL をそのまま、Google Classroom の「資料」や Teams などで配布する
    （タブレットのホーム画面に追加しておくと、毎時間すぐ開けます）
19. **先生用**：スプレッドシートのメニュー **「ふりかえり」→「先生用ページを開く」** から開く（生徒用ページのいちばん下の「先生用ページ」リンクでも同じ）
    - 表示されるのは最後が **`/dev?page=teacher`** の URL です。持ち主の先生だけが開けるテスト用の URL で、**デプロイし直さなくても、いつも最後に保存したコードで動きます**。これをブックマークしてください
    - 17. の URL（`/exec`）の最後に `?page=teacher` を付けても開けますが、その場合はコードを貼りかえるたびに「新バージョン」でデプロイし直す必要があります
    ⚠ 「デプロイを管理」には **ライブラリ** の URL（`…/macros/library/d/…`）も表示されることがあります。これを開くと関数の一覧が出るだけで、アプリは開きません。使うのは **ウェブアプリ** の URL（最後が `/exec`）です
    例）`https://script.google.com/macros/s/AKfy……/exec?page=teacher`
    → B. で決めたパスコードを入れると集計画面と **今日の合言葉** が表示されます。ブックマークしておきましょう
20. 試しに自分で生徒用 URL から1回送信し、先生用ページに出てくれば設置完了です

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| メニューに「ふりかえり」が出ない | 貼りつけ後に保存したか確認 → スプレッドシートを再読み込み（F5）して数秒待つ |
| 先生用ページが開けない（「ファイルを開くことができません」など） | スプレッドシートのメニュー「ふりかえり」→「先生用ページを開く」から開く（正しいURLが表示されます） |
| 先生用・生徒用ページがおかしい（原因がわからない） | Apps Script のエディタで関数 **`checkSetup`** を選んで ▶実行 → 下の「実行ログ」に、コードの版・URL・各ページが作れるかが表示されます。生徒用ページのいちばん下の「ver …」と版が同じか確かめます |
| 先生用ページで「パスコードがまだ設定されていません」 | B. の手順でパスコードを設定する |
| 生徒が「アクセス権がありません」と出る | 15. の「アクセスできるユーザー」を確認。変えるときは「デプロイ」→「デプロイを管理」→ ✏ →変更→「デプロイ」 |
| 合言葉がちがうと言われる | 先生用ページで今日の合言葉を確認。「毎日自動でかわる」なので前の日の数字は使えません |

> ⚠ **あとから `gacha.gs` を新しいものに貼りかえたとき**は、「デプロイ」→「デプロイを管理」→ ✏（編集）→ バージョン **「新バージョン」** →「デプロイ」をしないと、生徒の画面に反映されません（URLは変わりません）。パスコードと回答データは残ります。

### 授業での使い方

1. 授業の最後に先生用ページを開き、**今日の合言葉**を板書する（「大きく表示」でプロジェクターに映してもOK）
2. 「ふりかえりを送信しよう」と指示する（3〜5分）
3. 生徒のタブレット（iPad・Chromebook・Windows）のブラウザで動きます。アプリのインストールは不要です

---

### 回答を消したいとき（試しに取ったアンケートなど）

1. 先生用ページで学年・組を選んで「表示する」
2. **1回分の授業をまるごと消す** →「📅 授業ごと」でその授業を選び、**「この授業の回答をすべて削除」**
   **一部だけ消す** →「📅 授業ごと」または「👤 個人」で、消したい回答の左の □ にチェック →**「選んだ回答を削除」**
   （表の見出しの □ を押すと、表示中の回答をすべて選べます）
3. 確認の画面で内容を確かめて「OK」

- 消した回答は、スプレッドシートの **「削除済み」シート** に移ります（いちばん右の列に「削除した日時」が入ります）。まちがえて消したときは、その行を「回答」シートの最後にコピーして戻し、右端の「削除した日時」だけ消してください
- 「削除済み」シートの中身は、先生用ページの集計には入りません。不要になったら、シートごと削除してかまいません

## 5. データとセキュリティ

- 回答は **先生のスプレッドシートにだけ** 保存されます（外部のサービスには送られません）
- 生徒は **自分の回答を送ることしかできません**。他の生徒の回答を見る機能はありません
- 先生用ページはパスコードで保護しています。パスコードはプログラムの中には書かれず、Google のサーバー側（スクリプト プロパティ）に保存されます。生徒の画面には送られません
- 「全員」で公開した場合、だれが送ったかは確認できません（なりすましは防げません）。合言葉は「授業に出ていない人からの送信」を防ぐためのものです
- 生徒が学校のアカウントでログインしている場合は、スプレッドシートの「アカウント」列にメールアドレスも記録されます（なりすましの確認用）。先生用ページには表示しません
- 回答の削除は先生用ページからできます。文字の修正は、スプレッドシートの「回答」シートを直接編集してください（列の並びは変えないでください）
- 記述欄は1つ1000文字まで。`=` などで始まる文字は数式にならないよう処理しています

## 6. カスタマイズ

ふつうは変更不要です。変える場合は、Apps Script の「コード.gs」（貼りつけた `gacha.gs`）を直接書きかえて保存し、上の「新バージョン」でデプロイし直してください。

| したいこと | 変更する場所（「コード.gs」の中） |
|---|---|
| クラス数・出席番号の上限 | 上のほうの `CONFIG` の `CLASSES` / `MAX_NUMBER` |
| ガチャをやめる | `CONFIG` の `GACHA: true` を `false` に |
| 出る確率 | `CONFIG` の `RATES: { N: 60, R: 28, SR: 10, SSR: 2 }`（割合なので合計が100でなくてもOK） |
| 1日にガチャを引ける回数 | `CONFIG` の `GACHA_MAX_PER_DAY: 2` |
| キャラの追加・差しかえ | `src/chars.js` と `art/`（上の「3-1」） |
| 時限の欄をなくす | `CONFIG` の `MAX_PERIOD: 6` を `0` に |
| フォームの見出しの教科名 | `CONFIG` の `SUBJECT: '技術'` |
| A・B・C の説明文 | Ctrl＋F で `よく理解できた` などを探して書きかえる |
| 年度がかわったとき | スプレッドシートを「ファイル」→「コピーを作成」して新年度用にする（コピーしたものは A.〜C. の B・C をやり直し） |

- `gacha.gs`：Google のサービスを模した環境で、回答の保存と入力チェック、合言葉（まちがいは拒否）、ガチャ（送信で1回引ける、同じ授業の2回目・1日3回目は引けない、別の生徒・次の日は引ける、入力エラーのときは引かない、「ガチャ」「ガチャ履歴」シートへの記録、図鑑の読み出し、範囲外の学年・組・番号は拒否）、出る確率（20万回引いて N 60%・R 28%・SR 10%・SSR 2% に一致）、キャラのいないレア度は出ないこと、先生用・生徒用ページが作れること（checkSetup）をテスト。埋めこんだ画面（HTML）が元ファイルと1文字も違わないことも確認
