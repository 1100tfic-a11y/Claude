# 道徳ワークシート作成スキル

道徳の授業で配布する **A4縦・1枚** のワークシートを、同じフォーマットで作成するためのスキルです。
ベースは同じフォルダの `template.html`（印刷用CSS入りのHTML）。完成例は `example.html`。

## 必ず入れる構成（上から順に・順番を変えない）

| # | 欄 | 内容 |
|---|---|---|
| ① | 日付 | 「令和　年　月　日（　）」の手書き欄 |
| ② | クラス・番号・名前 | 「　年　　組」「番号」「名前」の3枠 |
| ③ | 資料のタイトル | 「資料名」＋ 大きく「〇〇」。下に内容項目（例：Ｂ 友情、信頼） |
| ④ | 名言・セリフの穴埋め | 資料に関わる名言／登場人物のセリフ。**キーワードの一部を空欄**にし、ア・イ…の記号を付ける |
| ⑤ | 問１～問３ | 各問に発問文と罫線付きの記入欄 |
| ⑥ | 今日の振り返り | 見出し「☆今日の振り返り（自分の感じたこと、自分に生かせそうなこと）」＋右に「とても ← ふつう → ぜんぜん」。<br>枠内に **自己評価3項目×５段階（5・4・3・2・1）の表**、その下に「今日の授業で考えたことを書きましょう。『（振り返りの問い）』」と点線の記入行3本 |

## 作り方

1. **情報を集める**：依頼から次を読み取る。足りないものだけ質問する（推測で埋められるものは埋めて、最後に「仮に入れた」と伝える）。
   - 資料名（教材名）、学年（小・中）、内容項目
   - 穴埋めにする名言・セリフ（指定がなければ資料の主題に合う言葉を提案）
   - 問１～問３の発問（指定がなければ下の「発問の組み立て」に沿って作る）
   - 振り返りの問い `{{振り返りの問い}}`（『』の中に入る、本時のねらいを自分の経験につなげる問い。例：「あなたがこれまでに誰かを励まそうとして掛けた言葉が、逆に相手を苦しめてしまったと思うことはある？相手は何を求めていたと思う？」）
2. **テンプレートをコピー**：`template.html` を出力先（例：`worksheets/YYYYMMDD_資料名.html`）へコピーし、`{{…}}` をすべて置き換える。`{{` が1つも残っていないことを確認する。
3. **穴埋めの作り方**
   - 空欄は `<span class="blank" data-n="ア" style="--w:5em"></span>`。`--w` は答えの文字数＋1〜2em程度。ア・イの記号は枠の左上（枠内）に小さく表示される。
   - 空欄は **1〜3か所**。資料の主題（価値）に直結する語を抜く。助詞や答えが一意に決まらない語は抜かない。
   - 語群が不要なら `<div class="choices">` の行を削除する。語群を出すときはダミーを1〜2語混ぜる。
   - 教科書の本文を長く引用しない。名言・セリフは1〜2文にとどめ、出典（発言者・資料名）を `.src` に書く。
4. **発問の組み立て**（指定がないとき）
   - 問１：場面の把握・登場人物の気持ち（「〜のとき、〇〇はどんな気持ちだったでしょう」）
   - 問２：中心発問。価値について深く考える（「なぜ〇〇は〜できたのだろう」）
   - 問３：自分との関わり（「あなたなら」「これまでの自分をふり返って」）
   - 発問は1〜2行に収める。小学校低学年はひらがなを多めに、中学校は常用漢字で。
5. **1枚に収まるか確認**：Chromium で PDF化してページ数を確認する。
   ```bash
   CH=$(ls -d /opt/pw-browsers/chromium*/chrome-linux*/chrome 2>/dev/null | head -1)
   "$CH" --headless --no-sandbox --no-pdf-header-footer \
         --print-to-pdf=出力.pdf "file://$PWD/出力.html"
   pdfinfo 出力.pdf | grep -E 'Pages|Page size'   # Pages: 1 / A4 であること
   ```
   2ページになったら、発問文・名言・振り返りの問いを短くするか、`.q1/.q2/.q3` の `flex` 値で問欄の高さ配分を調整する（例：中心発問の問２を広くする → `.q2 { flex: 3.4; }`）。振り返り欄は高さ固定（自己評価表＋点線3行）。
6. **渡す**：HTMLとPDFの両方を渡す。HTMLはブラウザで開いて「印刷 → A4・余白なし（既定）・倍率100%」で印刷できる。

## 変えてよいもの／変えないもの

- 変えてよい：問欄の高さ配分（flex）、空欄の数と幅、語群の有無、振り返りの問い（『』の中）、内容項目の表示。
- 変えない：A4縦1枚、①〜⑥の順番と見出し名（「問１」「☆今日の振り返り」など）、自己評価3項目の文言と５段階（5〜1）、白黒印刷で読める配色。
- 先生から恒久的な変更（欄の追加・名称変更など）を頼まれたら、`template.html` とこの SKILL.md を更新して以後のベースにする。
