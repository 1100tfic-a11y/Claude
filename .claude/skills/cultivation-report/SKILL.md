# 栽培観察レポート（技術科・生物育成）

`scripts/make_report.py` が、次の構成の Word ファイルを1つ作ります。すべて **A4 縦・1日1枚**。

| ページ | 内容 |
|---|---|
| 表紙 | 「〈作物名〉の栽培観察レポート」、年・組・番、名前、観察・栽培期間（開始日〜終了日）、観察日数 |
| 観察日記（月〜金の各日） | 第○日目・日付・曜日／天気・気温・観察時刻／**写真を貼る欄**／**一番大きい株の背丈（cm）**・**葉の枚数（枚）**・前回からの変化／今日した手入れ（チェック欄）／**観察・手入れの記録と考察**（罫線15行） |
| 収穫後のまとめ | 収穫日・収穫量・最後の背丈・葉の枚数・栽培日数／収穫物の写真欄／育ててわかったこと・工夫したこと・改善点・生活や社会とのつながり |

全ページのヘッダーに作物名と「年 組 番 名前」が入ります（表紙は除く）。Word でヘッダーに名前を1回書けば、全ページに反映されます。
記入欄はすべて表のセルなので、生徒は Word 上で直接入力・写真の挿入ができます。印刷して手書き＋写真をのりで貼る使い方もできます。

## 手順

1. **必要な情報を確認する。** 足りないものだけ聞く。
   - 必須：**作物名**、**開始日**、**終了日**（年が無ければ今年として扱う）
   - 任意：学年・組・番号・名前（空欄なら記入欄として残す。クラス全員分の配布用なら空欄でよい）
   - 任意：除外したい平日（祝日・行事・長期休業など）。祝日は自動では除外しないので、期間内の祝日を確認して `--skip` に入れる
   - 任意：写真フォルダ（ファイル名に日付を含むもの）
2. **スクリプトを実行する。**

   ```bash
   python3 .claude/skills/cultivation-report/scripts/make_report.py \
     --crop ミニトマト --start 2026-05-11 --end 2026-07-17 \
     --grade 2 --klass 3 --number 15 --name "山田 太郎" \
     --skip 2026-07-20 \
     --photos ./photos --pdf -o ミニトマト_栽培観察レポート.docx
   ```

   | オプション | 意味 |
   |---|---|
   | `--crop` | 作物名（タイトルとヘッダーに入る） |
   | `--start` / `--end` | 観察・栽培期間 `YYYY-MM-DD`。この間の **月〜金だけ** が1日1ページになる |
   | `--grade` `--klass` `--number` `--name` | 学年・組・番号・名前（省略可） |
   | `--skip` | 除外する平日をカンマ区切りで |
   | `--photos` | 写真フォルダ。`2026-05-11.jpg`／`20260511.jpg`／`0511.jpg` のように日付を含む名前はその日の写真欄に、`harvest.jpg`（または「収穫」を含む名前）はまとめページに自動で貼る |
   | `--pdf` | LibreOffice（`soffice`）で PDF も作る（印刷・手書き用） |
   | `-o` | 出力ファイル名（省略時は `<作物名>_栽培観察レポート.docx`） |

   依存：`python-docx`、`Pillow`（写真の縦横比の計算）。PDF 化には LibreOffice。
3. **確認する。** `--pdf` を付けて作り、`pdfinfo` のページ数が「表紙1＋観察日数＋まとめ1」と一致すること（1日分が2ページにはみ出していないこと）を確かめる。必要なら `pdftoppm -r 60 -png -f 2 -l 2 file.pdf p` で1ページを画像にして見た目を確認する。
4. **渡す。** 作成した .docx（と .pdf）をユーザーに送り、ページ数と期間、除外した日を一言で伝える。

## 調整するとき

`scripts/make_report.py` の先頭の定数と各関数を編集する。

- 手入れのチェック項目：`CARE_ITEMS`（作物に合わせて「土寄せ」「摘果」「人工授粉」などに入れ替え可）
- フォント：`FONT`（既定は Windows 標準の BIZ UDPゴシック）
- 写真欄の高さ・考察の行数：`day_page()` の `photo_box(doc, 92, …)` と `ruled_lines(doc, 15)`
- まとめの項目：`summary_page()` のリスト

行数や写真欄を大きくすると1日が2ページにはみ出すことがある。変更したら必ず手順3でページ数を確認する。
