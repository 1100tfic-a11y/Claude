## 携帯ゲームのドット絵を使う（おすすめ）

攻略サイトなどで見つけた、デジモンの携帯ゲームのドット絵（16×16ドット）を使って、
液晶の場面（子どもがタイピングし、デジモンが歩いて技を出すアニメーション）を作れます。

1. `images/custom/sprites/` フォルダを作り、デジモンの名前でドット絵を保存する

   | ファイル名 | デジモン |
   |---|---|
   | `agumon.png` / `agumon.gif` | アグモン |
   | `gabumon.*` | ガブモン |
   | `piyomon.*` | ピヨモン |
   | `tentomon.*` | テントモン |
   | `palmon.*` | パルモン |
   | `gomamon.*` | ゴマモン |
   | `patamon.*` | パタモン |
   | `tailmon.*` | テイルモン |

2. 次のコマンドを実行する

   ```
   python3 .claude/skills/digimon-crew/tools/make_sprites.py
   ```

3. `images/custom/<画像ID>.gif`（例：`taichi-agumon.gif`）ができ、次から自動でこちらが表示されます

**読み込みのしくみ**
- 拡大された画像でも、1ドットの大きさを自動で見つけて 16×16 に戻します（1倍・3倍・7倍・8倍・10倍で確認済み）
- 暗いドットを輪郭として残し、輪郭に囲まれた内側をそのデジモンの色で塗ります
- アニメーション GIF なら、そのコマ（足ぶみなど）をそのまま使います。1枚だけなら、足ぶみの動きを自動で付けます
- 形式は PNG と GIF。JPG などは Pillow が入っていれば読めます

**うまくいかないとき**
- 画像は **ドット絵1体だけ** になるように切り抜いてください（背景の模様や文字が入ると、それもドットとして読まれます）
- 本体の液晶を撮った写真は、ゆがみやぼけでドットの格子がずれるため、うまく読めません
- 輪郭が閉じていない絵は、内側が塗られず白いままになります

ここに置いたドット絵も、できた GIF も、GitHub には上がりません（`.gitignore` で除外しています）。
