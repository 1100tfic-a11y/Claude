# 自分で用意した画像の置き場所

このフォルダの中身は **GitHub に上がりません**（`.gitignore` で除外しています）。
公式のイラストやドット絵などの著作物は、個人で楽しむ範囲で、ここに置いて使ってください。

## 画像をそのまま差し替える

ここに、デジモンの名前の画像（png / jpg / jpeg / gif / webp）を置くと、オリジナルのドット絵の代わりに表示されます。
例：`agumon.gif`

使える名前：`agumon` / `gabumon` / `piyomon` / `tentomon` / `palmon` / `gomamon` / `patamon` / `tailmon`

## 携帯ゲームのドット絵から、作業中のアニメーションを作る

1. `sprites/` フォルダを作り、デジモンの名前でドット絵を保存する（例：`sprites/agumon.gif`）
2. 次のコマンドを実行する

   ```
   python3 .claude/skills/digimon-crew/tools/make_sprites.py
   ```

3. そのドット絵のデジモンがノートPCで作業している `agumon.gif` などがこのフォルダにでき、次から自動でこちらが表示されます

**読み込みのしくみ**
- 拡大された画像でも、1ドットの大きさを自動で見つけて元のドットに戻します（32×32 まで。16×16 以下の絵は2倍にして場面に置きます）
- 上下左右を輪郭に囲まれた1ドットの点（目の光など）は白にします
- 暗いドットを輪郭として残し、輪郭に囲まれた内側をそのデジモンの色で塗ります
- アニメーション GIF なら、そのコマ（足ぶみなど）をそのまま使います。1枚だけなら、はずむ動きを自動で付けます
- 形式は PNG と GIF。JPG などは Pillow が入っていれば読めます

**うまくいかないとき**
- 画像は **ドット絵1体だけ** になるように切り抜いてください（背景の模様や文字が入ると、それもドットとして読まれます）
- 本体の液晶を撮った写真は、ゆがみやぼけでドットの格子がずれるため、うまく読めません
- 輪郭が閉じていない絵は、内側が塗られず白いままになります
