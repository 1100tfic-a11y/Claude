# デジモン・クルー（作業中のドット絵）

このリポジトリでは、Claude が作業している間、**パートナーデジモンがノートPCに向かって作業している動くドット絵** を表示する。
セリフやキャラクターの口調は使わない。返答の文章はふだんどおりに書く。

## 1. 表示するデジモン（現在はアグモンだけ）

**現在は、どの作業でもアグモンだけを表示する。** 表示するのは、ユーザーが用意した
`images/custom/agumon.gif`（携帯ゲームのドット絵に色を付けて、ノートPCで作業させたもの）。

- `images/custom/agumon.gif` が無い場合は、画像は出さない（オリジナルの `images/agumon.gif` などで代用しない）。その会話で最初の1回だけ、`custom/agumon.gif` と `custom/sprites/agumon.png` を置けば表示されることを一言案内する。
- ほかのデジモン（`images/gabumon.gif` など）のファイルは、今後キャラを追加するときのために残してあるが、ユーザーの指示があるまで表示しない。

## 2. 画像の出し方

1. `images/custom/agumon.gif` があることを確かめる。
2. `SendUserFile` でその画像を送る（`display: "render"`、`status: "normal"`）。`caption` は付けないか、作業内容を一言（例：「テスト中」）。

**出すタイミング**
- 作業開始時と最終報告の2回（質問への回答だけの短いターンは1回）。

## 3. デザインを勝手に変えない

**ユーザーの指示があるまで、絵・色・場面・動きのデザインは変更しない。**
`images/` の画像、`images/custom/` の中身、`tools/digimon_art.py` と `tools/make_sprites.py` の絵や場面にかかわる部分は、頼まれないかぎり編集・作り直しをしない。改善の案があっても、提案するだけにとどめる。

## 4. 絵について

- 場面：デジモンが机のノートPCでタイピングしている。画面にコードが流れ、進捗バーが伸びて、最後にチェックが付く。頭の上には技のエフェクト（アグモンは炎、テントモンは電気、パルモンは花びら など）。
- デジモンの絵は `tools/digimon_art.py`（32×32・図形の組み合わせ）、場面と GIF の書き出しは `tools/make_sprites.py`。どちらも外部ライブラリ不要。絵はすべてオリジナル。
- ユーザーが `images/custom/sprites/<デジモン名>.png|gif` に携帯ゲームのドット絵を置いた場合は、`make_sprites.py` を実行すると、それを読み込んで色を塗った場面が `images/custom/<デジモン名>.gif` にでき、`pick-image.sh` がそちらを優先する（読み込み処理は `tools/vpet_import.py`）。
- `images/custom/` の中身はユーザー個人のもので、GitHub に上げない（`.gitignore` 済み）。公式の画像やドット絵を Claude が取得してリポジトリに入れてはいけない。

## 5. 守るべきルール

- 画像は演出。技術的な説明と結果は、ふだんどおり正確に書く。
- コード・コミットメッセージ・PR・README・アプリには画像や演出を入れない（ユーザーが求めた場合を除く）。
- `SendUserFile` が使えない環境（ローカルのターミナルなど）では画像は出さない。
- ユーザーが「演出オフ」と言ったら、その会話では画像を出さない。
